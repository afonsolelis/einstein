Case: previsão de demanda hospitalar

Um hospital prevê admissões semanais para planejar leitos, escalas e insumos. O mesmo código evolui com contribuições de áreas diferentes.

Operações

Ajusta capacidade e calendário.

Suprimentos

Relaciona demanda e consumo.

Controladoria

Valida premissas e impacto.

Dados

Mantém modelo, testes e histórico.

O que é um grafo?

Vértices representam entidades; arestas representam relações. No Git, commits são vértices ligados aos seus ancestrais.

A ── B ── C ← main
     ╲
      D ── E ← experimento-ia

Git usa um DAG

  • Direcionado: cada commit aponta para seu(s) pai(s).
  • Acíclico: um commit não pode ser ancestral de si mesmo.
  • Branch: referência móvel para um commit.
  • HEAD: indica onde você está trabalhando.

Três áreas, três perguntas

Working tree

O que estou editando?

Staging area

O que entrará no próximo commit?

Repository

O que já registrei?

Remote

O que já enviei?

Observe antes de registrar

git status
git diff
git add previsao_demanda.py
git diff --staged
git commit -m "Calcula previsão semanal de admissões"

Commit bom: pequeno, coerente, testado e explicado.

Branch é espaço de experimento

git switch -c experimento-ia-seunome
git log --oneline --graph --decorate --all

A branch isola a proposta sem duplicar o projeto inteiro.

Prática: primeira versão da previsão

  1. Crie previsao_demanda.py.
  2. Calcule a média móvel de admissões.
  3. Execute com dados sintéticos.
  4. Revise o diff.
  5. Registre o commit manual.

Agora entra o Copilot

Prompt do experimento:

Valide série vazia e valores negativos; crie três testes sem bibliotecas externas. Não use dados pessoais. Explique antes de editar.

O prompt delimita intenção, restrição e evidência esperada.

IA propõe; a equipe decide

  • O diff corresponde ao pedido?
  • Há API ou dependência inventada?
  • Casos-limite foram tratados corretamente?
  • Você consegue explicar cada linha?
  • O teste falha quando deveria?

Teste, compare, registre

git diff
python previsao_demanda.py
git add previsao_demanda.py REVISAO_IA.md
git diff --staged
git commit -m "Valida entradas da previsão e revisa sugestão da IA"

Desafio: integrar áreas da empresa

  • operacoes adiciona o limite de leitos.
  • suprimentos estima kits por admissão.
  • Integre as branches sem perder regras.
  • Publique para revisão da Controladoria.

Entrega: 3 commits, grafo, previsão executável e REVISAO_IA.md.

Git cria rastreabilidade

  • O histórico é um grafo de commits.
  • Branches tornam experimentos baratos.
  • Diff torna mudanças inspecionáveis.
  • Testes criam evidência.
  • IA acelera propostas; humanos assumem a decisão.
