Case do comitê financeiro

O comitê financeiro de um grupo hospitalar acompanha mensalmente as empresas de saúde listadas na B3, porque elas são concorrentes, compradoras de serviços e referência de valor para o setor. Hoje esse acompanhamento é feito com planilhas copiadas à mão.

  • Quais empresas do setor superaram o Ibovespa no período?
  • Quais oscilaram mais e quanto chegaram a cair a partir de um pico?
  • As ações do setor sobem e caem juntas?

O que é uma API de dados

Uma API é um endereço que devolve dados estruturados quando recebe um pedido em formato combinado. O painel deixa de depender de uma cópia manual, porque cada atualização refaz a consulta na fonte.

  • O Yahoo Finance publica cotações, e a biblioteca yfinance faz o pedido e entrega um DataFrame.
  • A biblioteca não é um produto oficial do Yahoo: a API pode mudar, limitar pedidos ou atrasar dados.
  • As cotações chegam com atraso e servem para estudo, não para operar na bolsa.

Como o Yahoo nomeia os ativos

RDOR3.SARede D'Or
HAPV3.SAHapvida
FLRY3.SAFleury
RADL3.SARaia Drogasil
^BVSPIbovespa

O sufixo .SA indica ações negociadas na B3, e o acento circunflexo indica um índice. O dólar comercial aparece como USDBRL=X.

Passo 1 · Primeira consulta

import pandas as pd import yfinance as yf rdor = yf.Ticker("RDOR3.SA") historico = rdor.history(period="6mo") historico.tail()

Cada linha é um pregão, com abertura, máxima, mínima, fechamento, volume, proventos e desdobramentos.

Passo 2 · Vários ativos em base 100

tickers = ["RDOR3.SA", "HAPV3.SA", "FLRY3.SA", "RADL3.SA", "^BVSP"] dados = yf.download(tickers, period="1y", auto_adjust=True, progress=False) fechamento = dados["Close"].dropna() base_100 = fechamento / fechamento.iloc[0] * 100 base_100.plot(figsize=(10, 4), title="Base 100 no início do período")

O Ibovespa vale cerca de 200 mil pontos e a Hapvida menos de R$ 10. Dividir cada série pelo primeiro valor coloca todas no mesmo eixo e evita o gráfico de dois eixos.

Três indicadores para o comitê

  • Retorno no período: variação entre o primeiro e o último fechamento.
  • Volatilidade anualizada: desvio padrão dos retornos diários multiplicado por √252, o número aproximado de pregões em um ano.
  • Queda máxima: a maior perda medida a partir do pico anterior, que indica o pior momento de quem comprou no topo.

O parâmetro auto_adjust=True desconta dividendos e desdobramentos, sem o que um grupamento de ações apareceria como queda.

Passo 3 · Tabela de indicadores

retornos = fechamento.pct_change().dropna() resumo = pd.DataFrame({ "retorno_pct": (fechamento.iloc[-1] / fechamento.iloc[0] - 1) * 100, "volatilidade_pct": retornos.std() * 252 ** 0.5 * 100, "queda_maxima_pct": (fechamento / fechamento.cummax() - 1).min() * 100, }).round(1).sort_values("retorno_pct", ascending=False) resumo

Do notebook ao painel

O notebook responde às perguntas de quem o escreveu. O painel permite que o comitê escolha empresas e período sem ler código.

  • O Streamlit executa o arquivo app.py de cima a baixo a cada clique em um filtro.
  • Por isso a consulta à API fica em uma função com @st.cache_data, que guarda o resultado por 15 minutos e poupa pedidos ao Yahoo.
  • Filtros ficam em uma linha acima dos gráficos, e todos os gráficos respondem a eles.

Passo 4 · Filtros e consulta com cache

Crie aula-10-seunome/app.py com o início do painel:

import streamlit as st import yfinance as yf st.title("Empresas de saúde na B3") opcoes = ["RDOR3.SA", "HAPV3.SA", "FLRY3.SA", "RADL3.SA"] tickers = st.multiselect("Empresas", opcoes, default=opcoes[:2]) periodo = st.selectbox("Período", ["3mo", "6mo", "1y", "2y"], index=2) @st.cache_data(ttl=900) def baixar(tickers, periodo): dados = yf.download(list(tickers) + ["^BVSP"], period=periodo, auto_adjust=True, progress=False) return dados["Close"].dropna()

Passo 4 · Gráfico que responde aos filtros

Complete o arquivo com as linhas abaixo. Sem empresa selecionada, st.stop() encerra a execução antes de chamar a API.

if not tickers: st.stop() fechamento = baixar(tuple(tickers), periodo) st.line_chart(fechamento / fechamento.iloc[0] * 100)

A tupla é necessária porque o cache identifica cada chamada pelos argumentos, e listas não servem como chave.

Passo 5 · Rodar e abrir pela aba PORTS

streamlit run aula-10-seunome/app.py
  1. O terminal informa que o app está na porta 8501.
  2. Abra a aba PORTS do Codespace, localize a porta 8501 e clique no globo.
  3. O endereço localhost:8501 não funciona no seu navegador, porque o app roda na máquina do Codespace.
  4. Para encerrar, use Ctrl+C no terminal.

Cuidados ao ler o painel

  • Uma queda brusca pode ser um evento da empresa ou um erro de dado. Antes de concluir, confira a data na página de relações com investidores.
  • Correlação alta indica que os preços se movem juntos, não que um causa o outro.
  • O retorno depende do período escolhido: troque de 1 ano para 2 anos e veja se a ordem muda.
  • O painel descreve o passado e não constitui recomendação de investimento.
