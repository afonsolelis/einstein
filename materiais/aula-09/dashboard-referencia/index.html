Estratégias comerciais da Olist para 2019

As dez perguntas do Chief de Vendas, respondidas pelas views do esquema estrela no seu Supabase. Nenhum número desta página está escrito no HTML: tudo vem da API REST no momento em que você abre o painel.

Conecte o seu projeto Supabase

Em Project Settings → API Keys, copie a chave publicável (sb_publishable_…; em projetos antigos, a anon public). A Project URL tem o formato https://<ref>.supabase.co, com o <ref> que aparece no endereço do painel, depois de /project/. A chave secreta e a senha do banco nunca entram aqui.

Sem /rest/v1 no final: o painel acrescenta.
Ela identifica o projeto; quem limita a leitura é o RLS e o grant select das views.

Convenções. Receita é a soma do preço dos itens, sem frete, de pedidos com status delivered. O período cobre os meses completos da base, de janeiro de 2017 a agosto de 2018.

Origem. Views de materiais/aula-08/olist/views.sql, sobre o esquema estrela de materiais/aula-07/olist/estrela.sql, lidas pela API REST do Supabase com a chave publicável.

Privacidade. A URL e a chave ficam apenas no localStorage deste navegador; o GitHub Pages só entrega os arquivos estáticos.
